# Monitoring Skill

Use this skill when setting up monitoring.

## Requirements
- Track system performance, error rates, and uptime metrics.
- Configure alerting triggers for critical system thresholds.
- Maintain real-time dashboards for application health.

## Checks
- Verify telemetry collection and error reporting integrations.
- Test notification alerts for simulated service failures.
- Ensure latency and error metrics are recorded accurately.
