# Payment Architecture Skill

Use this skill when designing payment flows.

## Requirements
- Design end-to-end payment processing pipelines.
- Integrate gateway adapters, ledger tracking, and state machines.
- Ensure security, compliance, and error resiliency in payment paths.

## Checks
- Validate transactional boundaries across payment state updates.
- Verify separation of concern between payment UI and payment execution.
- Ensure audit logging is active across all payment steps.
