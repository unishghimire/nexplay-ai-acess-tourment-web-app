# React Skill

Use this skill when working with React components and hooks.

## Requirements
- Use functional components with custom hooks where beneficial.
- Follow React best practices for state management and effects.
- Prevent unnecessary re-renders with memoization when appropriate.

## Checks
- Verify dependency arrays in `useEffect` and `useCallback`.
- Check component prop types and default prop values.
- Test state transitions and component lifecycle behavior.
