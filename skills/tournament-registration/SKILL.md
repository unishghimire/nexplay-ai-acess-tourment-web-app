# Tournament Registration Skill

Use this skill when implementing tournament registration.

## Requirements
- Manage entry fees, player registration limits, and slot assignments.
- Process participant registration and check-in workflows seamlessly.
- Handle registration refunds or cancellations according to rules.

## Checks
- Verify capacity limits prevent over-registration.
- Test simultaneous user registration for race conditions.
- Confirm registration fee deduction and refund mechanisms.
