# Integration Testing Skill

Use this skill when writing integration tests.

## Requirements
- Test interactions between modules, databases, and APIs.
- Validate data flow across component boundaries and store modules.
- Ensure mock servers or emulators reflect production behavior accurately.

## Checks
- Run integration tests with database emulators or test DBs.
- Verify transactional rollback or cleanup after test runs.
- Check error propagation through multi-layer calls.
