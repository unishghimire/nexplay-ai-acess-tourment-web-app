# Performance Skill

Use this skill when optimizing performance.

## Requirements
- Minimize initial bundle size and enable lazy loading.
- Optimize asset delivery, caching, and database queries.
- Measure performance metrics like FCP, LCP, and CLS.

## Checks
- Audit bundle sizes using build analysis tools.
- Check network waterfall and reduce unneeded API requests.
- Verify UI responsiveness under high render loads.
