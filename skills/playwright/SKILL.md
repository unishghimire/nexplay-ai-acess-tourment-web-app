# Playwright Skill

Use this skill when writing Playwright E2E tests.

## Requirements
- Automate browser user journeys across dynamic pages.
- Handle asynchronous network calls and element waiting cleanly.
- Capture screenshots, traces, and video artifacts on failure.

## Checks
- Run Playwright test suite in headless mode.
- Verify tests pass across cross-browser environments (Chromium, Firefox, WebKit).
- Ensure test scripts are resilient against timing variations.
