# Repository Audit Skill

Use this skill when auditing the NexPlay repository for existing implementation.

## Requirements
- Inspect code structure and verify feature completeness.
- Identify unused code, dead imports, or obsolete configurations.
- Verify consistency across all repository submodules.

## Checks
- Confirm all expected files and routes are present.
- Check for duplicate or conflicting module definitions.
- Ensure code alignment with project specifications.
