# DevOps Skill

Use this skill when handling deployment or CI/CD.

## Requirements
- Automate build, test, and deployment pipelines.
- Manage environment variables and secrets securely.
- Ensure zero-downtime deployments and rollback capability.

## Checks
- Verify GitHub Actions workflow executions.
- Confirm deployment steps complete without warnings or errors.
- Ensure build artifacts match target environment configs.
