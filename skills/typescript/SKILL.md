# TypeScript Skill

Use this skill when writing or reviewing TypeScript code.

## Requirements
- Use strict TypeScript types and avoid using `any`.
- Define clear interfaces and types for data structures.
- Ensure clean compile-time type checking without errors.

## Checks
- Run `npx tsc --noEmit` to verify zero type errors.
- Check that type exports are organized logically.
- Ensure no implicit type coercion or unsafe assertions.
