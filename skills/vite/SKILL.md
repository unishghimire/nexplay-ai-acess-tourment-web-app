# Vite Skill

Use this skill when modifying Vite build configuration.

## Requirements
- Optimize Vite configuration for fast development and build speed.
- Configure path aliases, plugins, and environment variables.
- Ensure assets and code splitting are properly handled.

## Checks
- Verify `npm run build` succeeds without build errors.
- Test development server start times and HMR functionality.
- Confirm environment variable prefixing (`VITE_`).
