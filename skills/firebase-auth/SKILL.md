# Firebase Auth Skill

Use this skill when working on Firebase Authentication.

## Requirements
- Configure Firebase Auth providers and authentication rules.
- Handle user session state changes securely on client and server.
- Manage user profiles, custom claims, and auth tokens.

## Checks
- Test email/password, social login, and token refresh flows.
- Verify security rules restricting unauthenticated data access.
- Check proper error handling for invalid auth attempts.
