# Documentation Skill

Use this skill when updating documentation.

## Requirements
- Keep project documentation concise, accurate, and structured.
- Document API endpoints, environment setup, and skill usages.
- Ensure code comments and README files stay up to date.

## Checks
- Verify markdown formatting and relative link validity.
- Ensure no confidential or sensitive keys exist in docs.
- Check that new features or changes are reflected in guides.
