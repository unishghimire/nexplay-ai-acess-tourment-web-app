# Financial Ledger Skill

Use this skill when working on financial ledger.

## Requirements
- Record all financial transactions as immutable debit/credit entries.
- Ensure total debits equal total credits for balanced accounting.
- Support detailed auditability and transaction trace history.

## Checks
- Verify balance updates match ledger sum entries.
- Ensure ledger entries cannot be mutated or deleted post-creation.
- Check precision and rounding standards for currency amounts.
