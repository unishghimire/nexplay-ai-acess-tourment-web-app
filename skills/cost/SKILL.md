# Cost Skill

Use this skill when auditing or reducing costs.

## Requirements
- Monitor Cloud resource consumption and API call frequencies.
- Optimize caching strategies to minimize database reads/writes.
- Eliminate redundant server or cloud function executions.

## Checks
- Verify Firestore read/write counts during typical user flows.
- Ensure caching layers reduce unnecessary backend traffic.
- Check for unused cloud resources or abandoned services.
