# Firebase Deployment Skill

Use this skill when deploying to Firebase.

## Requirements
- Deploy hosting, rules, and Cloud Functions reliably.
- Support environment-specific deployment targets (staging, production).
- Maintain zero downtime during deployment rollouts.

## Checks
- Verify `firebase.json` target configurations.
- Test `npm run deploy` scripts in CI/CD pipeline.
- Confirm hosting rules and security rules are updated on deploy.
