# Unit Testing Skill

Use this skill when writing unit tests.

## Requirements
- Test individual functions and components in isolation.
- Mock external dependencies, APIs, and database calls.
- Maintain high code coverage and clear test descriptions.

## Checks
- Run unit test suite to verify fast execution and high pass rate.
- Check boundary conditions, null inputs, and error branches.
- Ensure test files follow proper naming conventions (`*.test.ts`).
