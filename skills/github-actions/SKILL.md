# GitHub Actions Skill

Use this skill when writing GitHub Actions workflows.

## Requirements
- Automate linting, testing, security checks, and deployment steps.
- Optimize workflow runtime using caching for npm and build artifacts.
- Keep workflow secrets and environment variables protected.

## Checks
- Validate workflow YAML syntax and step triggers.
- Run workflows and confirm clean step-by-step execution.
- Check that failing steps fail the pipeline appropriately.
