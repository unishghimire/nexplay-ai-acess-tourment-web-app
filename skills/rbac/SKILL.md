# RBAC Skill

Use this skill when implementing role-based access control.

## Requirements
- Define clear user roles and permission sets.
- Ensure consistent role checks across frontend UI and backend API.
- Maintain manageable role assignment and updating workflows.

## Checks
- Verify admin, moderator, and user permission boundaries.
- Test UI component visibility based on current user role.
- Ensure API endpoints reject operations exceeding role authority.
