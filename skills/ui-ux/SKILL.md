# UI/UX Skill

Use this skill when designing or reviewing UI/UX.

## Requirements
- Deliver intuitive, accessible, and user-friendly interface designs.
- Ensure visual consistency in typography, colors, and layout.
- Design responsive layouts for desktop, tablet, and mobile.

## Checks
- Verify WCAG accessibility contrast and keyboard navigation.
- Test UI components across multiple screen resolutions.
- Gather feedback on interaction flows and visual hierarchy.
