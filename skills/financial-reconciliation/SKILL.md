# Financial Reconciliation Skill

Use this skill when implementing reconciliation.

## Requirements
- Reconcile internal ledger balances with external payment provider reports.
- Detect, log, and alert on balance discrepancies or unsettled funds.
- Generate automated reconciliation summary reports.

## Checks
- Run daily reconciliation checks against mock and live gateway reports.
- Verify discrepancy flagging mechanism triggers appropriate alerts.
- Check tolerance margins for currency rounding differences.
