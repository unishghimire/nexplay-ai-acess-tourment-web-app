# Vercel Skill

Use this skill when configuring Vercel deployment.

## Requirements
- Configure build settings, serverless functions, and routing headers.
- Manage environment variables and deployment preview environments.
- Optimize asset caching and edge routing capabilities.

## Checks
- Verify `vercel.json` configuration and build commands.
- Test preview deployments for feature branches.
- Confirm custom headers and redirect rules function correctly.
