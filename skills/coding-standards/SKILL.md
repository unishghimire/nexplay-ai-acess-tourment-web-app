# Coding Standards Skill

Use this skill when writing or reviewing code for NexPlay.

## Requirements
- Enforce consistent code formatting and naming conventions.
- Follow modular architecture and clean code principles.
- Use meaningful variable names and typed interfaces.

## Checks
- Verify linting rules pass without warnings or errors.
- Check for code duplication and refactor redundant logic.
- Ensure file structure aligns with project conventions.
