# Payments Skill

Use this skill when modifying payment integrations.

## Requirements
- Handle payment gateways and transaction status updates safely.
- Ensure server-side validation for all payment requests.
- Implement robust logging and audit trails for financial events.

## Checks
- Verify webhook signature validation for payment events.
- Check idempotency handling for payment processing.
- Test success, failure, and edge-case payment states.
