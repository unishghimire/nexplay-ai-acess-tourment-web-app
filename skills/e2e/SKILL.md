# E2E Skill

Use this skill when writing end-to-end tests.

## Requirements
- Cover complete user journeys and application workflows.
- Use reliable selectors and resilient assertion strategies.
- Isolate test environments and cleanup created test data.

## Checks
- Verify E2E tests run successfully in headless environments.
- Check for flaky selectors or time-dependent assertions.
- Ensure failure screenshots or trace logs are captured.
