# Incident Response Skill

Use this skill when handling production incidents.

## Requirements
- Provide rapid triage, incident classification, and mitigation steps.
- Maintain clear incident communication and post-mortem reporting.
- Implement rollback procedures and hotfix workflows when required.

## Checks
- Verify incident escalation channels and response runbooks.
- Test database and code rollback capabilities.
- Ensure root-cause analysis documentation is created post-incident.
