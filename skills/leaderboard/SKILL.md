# Leaderboard Skill

Use this skill when working on leaderboard ranking.

## Requirements
- Compute user rankings based on points, wins, and tie-breakers.
- Support real-time leaderboard updates and caching strategy.
- Scale query performance for large participant numbers.

## Checks
- Verify ranking calculation accuracy across tie-breaker rules.
- Test cache invalidation and refresh upon match results.
- Check pagination and performance for high-traffic leaderboards.
