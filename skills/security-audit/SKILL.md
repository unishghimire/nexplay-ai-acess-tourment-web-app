# Security Audit Skill

Use this skill when performing security audits.

## Requirements
- Analyze system architecture and dependencies for security risks.
- Audit authentication, authorization, and data storage logic.
- Identify potential OWASP top 10 vulnerabilities in code.

## Checks
- Run dependency audit commands (`npm audit`).
- Check code for potential secret exposures or unsafe inputs.
- Verify encryption standards for data at rest and in transit.
